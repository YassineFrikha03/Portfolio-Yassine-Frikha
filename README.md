## 🛠️ Technologies Utilisées

### **Frontend & Framework**
- **React 19** — Bibliothèque UI déclarative et basée sur les composants
- **Vite 8** — Bundler et serveur de développement ultra-rapide
- **React Router 7** — Routage client fluide pour la navigation multipage
- **Lucide React** — Pack d'icônes vectorielles modernes et légères
- **i18next & react-i18next** — Gestion des traductions multilingues

### **Outils & Qualité**
- **CSS3 / Variables CSS** — Design system personnalisé sans dépendances CSS lourdes
- **Oxlint** — Linter JavaScript ultra-rapide basé sur Rust
- **Git & GitHub** — Versioning et hébergement du code source

## 📁 Structure du Projet

```text
mon-portfolio/
├── public/                 # Favicon haute résolution, icônes et assets statiques
│   ├── favicon.png
│   └── favicon.svg
├── src/
│   ├── assets/             # Images, logos et captures d'écran des projets
│   ├── components/         # Composants réutilisables
│   │   ├── About.jsx       # Section À propos
│   │   ├── Footer.jsx      # Pied de page avec liens et réseaux
│   │   ├── Hero.jsx        # En-tête avec présentation et stats
│   │   ├── Navbar.jsx      # Barre de navigation (thème, langue, liens)
│   │   ├── Projects.jsx    # Liste et filtre des projets
│   │   └── Skills.jsx      # Compétences et services proposés
│   ├── locales/            # Fichiers de traduction JSON
│   │   ├── en.json         # Traductions en anglais
│   │   └── fr.json         # Traductions en français
│   ├── pages/              # Pages principales
│   │   ├── Contact.jsx     # Formulaire et coordonnées
│   │   ├── HomePage.jsx    # Page d'accueil assemblée
│   │   └── ProjectDetailsPage.jsx # Fiche détaillée d'un projet
│   ├── i18n.js             # Configuration i18next
│   ├── App.jsx             # Configuration des routes
│   ├── App.css             # Styles globaux et composants
│   ├── index.css           # Thèmes (variables CSS sombre/clair)
│   └── main.jsx            # Point d'entrée React
├── index.html              # Fichier HTML racine
├── package.json            # Dépendances et scripts npm
└── vite.config.js          # Configuration Vite
```
